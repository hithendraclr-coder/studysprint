# StudySprint — Exam Countdown & Revision Planner

A responsive exam countdown and revision planner built with plain HTML, CSS, and JavaScript. No API key, build step, or backend is required.

## Run it
1. Keep `index.html`, `style.css`, and `script.js` together in the same folder.
2. Open `index.html` in a modern browser.
3. Add your exam dates, then add revision tasks linked to those subjects.

## Features
- Countdown for each exam, including today's and past exams.
- Add, edit, and delete exams.
- Add, edit, complete, filter, sort, and delete revision tasks.
- Smart planner prioritizes unfinished tasks using task priority, due date, and the next exam for that subject.
- Dashboard overview with completion percentage and today's tasks.
- Light/dark appearance toggle.
- Browser localStorage persistence.
- Reset all data with a confirmation prompt.
- Responsive layout for desktop and mobile.

## Important notes
- Data is saved in this browser on this device, not synced to other devices.
- Clearing browser site data may remove your saved plan. Keep a backup of important dates.
- StudySprint does not send operating-system notifications; reminders are represented by scheduled tasks inside the app.
- The planner's recommendations are simple rules-based suggestions, not AI or a substitute for your own study judgment.
